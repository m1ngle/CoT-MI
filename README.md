This repository contains code files for the dissertation of Melissa Ingle for National University in San Diego, California. This study explores how large language models interpret polysemous words — words with multiple related meanings such as bank, pitch, and tie — under different prompting strategies. The project compares direct prompting against Chain-of-Thought (CoT) prompting, as well as few-shot and zero-shot learning, to evaluate how these strategies influence model accuracy and internal reasoning behavior. Responses are statistically analyzed using McNemar testing and examined through mechanistic interpretability techniques using TransformerLens to observe how internal activation patterns evolve during disambiguation. The broader goal of the study is to investigate whether CoT reflects structured inference within LLMs or simply the probabilistic mimicry of human-like reasoning.
